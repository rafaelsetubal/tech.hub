# Arquivos-fonte do portfólio

Esta pasta preserva as gravações originais enviadas para o portfólio. Elas ficam
fora de `public/` para que os arquivos grandes de origem não sejam incluídos no
site publicado.

As versões leves usadas pela página e suas capas WebP ficam em
`public/portfolio/videos-techub/`. Para incluir outro projeto, preserve a fonte
aqui, gere um MP4 otimizado e uma capa WebP com o mesmo nome-base, coloque as
duas versões leves em `public/portfolio/videos-techub/` e cadastre o projeto em
`src/data/sitePortfolio.ts`.
